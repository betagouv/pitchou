## Comment voir les dossiers qui ne sont pas suivis ( qui ne sont attribué à personne ) ?

Sur l'onglet "Tous les dossiers" cliquez sur le bouton "Dossiers sans instructeur·ice".

## Onglet Mes Dossiers
Dans cette onglet vous pouvez voir tous les dossiers que vous suivez.

## Onglet Tous les dossiers
Dans cette onglet vous pouvez voir tous les dossiers des groupes auxquels vous appartenez.

## Comment suivre un dossier ?

Sur la ligne du dossier dans le tableau, cliquez sur l'étoile en haut à droite.
