# Development email capture

Set `MAILPIT_URL` to a local Mailpit HTTP endpoint when running with
`NODE_ENV=development` or `NODE_ENV=test`. For example,
`http://127.0.0.1:8025/`. The value may include a Mailpit webroot path.

HTML emails go to Mailpit instead of Brevo. Recipients, copies, reply address,
attachments and notification links remain available in the inbox. Capture needs
no Brevo API key. A failed capture never falls back to real delivery. Production
rejects this setting.

Hosted Brevo templates, including login emails, are unsupported. Capture accepts
emails whose HTML content is generated by the application.

Without `MAILPIT_URL`, existing Brevo delivery is unchanged. The shared Docker
Compose files and ordinary development recipes are unchanged too.

Open the configured Mailpit URL in a browser to inspect captured messages.
Capture verifies application output. It does not verify delivery through Brevo
or the rendering of templates hosted by Brevo, and it does not change when the
application schedules emails.
